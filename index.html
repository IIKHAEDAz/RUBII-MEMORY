คัดลอก Regex ลงช่องนิพจน์ และ HTML ลงช่องข้อความแทนที่ จากนั้นนำคำสั่งให้ AI ไปใส่ในพรอมต์ของตัวละคร ไม่ต้องใส่ CSS ส่วนกลาง

Regex จับจำนวนรอบได้ทุกชุด เช่น 1/2, 1/3 หรือ 8/8 โดย $1 คือจำนวนรอบ และ $2 คือเนื้อหาสรุป ใช้ white-space:pre-wrap เพื่อรักษาการขึ้นบรรทัด

โหมดบรรทัดเดียวใช้ <br> แทนการคั่นด้วย | จึงรองรับจำนวนข้อที่เพิ่มขึ้นได้โดยใช้กฎเดียว อย่าใช้ | แทนการขึ้นบรรทัดในกฎนี้

กล่องจะจับคู่ได้เมื่อแท็ก [/Memory] ครบแล้ว การโหลดระหว่างพิมพ์ขึ้นกับแอป ไม่สามารถรับประกันด้วย Regex อย่างเดียว ตัวอย่างในเว็บทดสอบการแทนที่แบบ JavaScript ไม่ใช่การทดสอบภายใน RUBII
